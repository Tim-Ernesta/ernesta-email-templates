Image block in every shape and format used by other molecules.

Figma: Molecules page, node `3033:1073` (https://www.figma.com/design/dAMxIWTCyv3Hk8nALva1GM/Ernesta-Email-Component-Library?node-id=3033-1073). Layer: Molecule.

Variants (Figma properties):

- **Size**: large, small
- **Shape**: rectangle, rectangle-vertical, square
- **Format**: fill, inlay
- **Mode**: none (fill), light, dark (inlay)

Used in: every image module.

Inlay sits the image inside a tinted frame; fill runs edge to edge.

Rendered reference: `references/renders/Molecules/image.jpg` (every variant, exported from Figma). Build the email HTML from that render and the tokens; apply the README rules for type, color and spacing.
