**Layout B** (desktop `3067:16124`, mobile `3067:16153`): Value prop marquee, Hero 700px, ProductFeature (product details over one 600x400 image), Ctas (single button), ImageTextStepsModule, SupportBar, PreHeader (SMS), Footer.
